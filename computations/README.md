# 初期の厳密計算

Python 3 の標準ライブラリだけを使う。

```bash
python3 computations/weighted_baseline.py
```

このコマンドは整数・有理数・Laurent 単項式の指数ベクトルで計算をやり直し、
現行の `baseline_certificate.json` と比較する。証明書を意図的に再生成する場合は
`--write` を付ける。数値標本や浮動小数点は使用しない。

## 検証する内容

- 指定した標準解消の重みシフトと、二変数 Euler 多項式
  `∏(1-s*t^w_i)`。`s` は語長、`t` は重みである。
- 重み 0〜24 の Hilbert 係数を、幾何級数の積・指数ベクトルの列挙・二重和で独立に照合する。
- 二次関係の各重みの周囲空間、標準関係数、および表示パラメータ空間の次元。
- 対角量子族 `x_j*x_i=q_ij*x_i*x_j` の全4個の重なり曖昧性。
- `x,y,z` が可換、`tx=xt+a*z*z`, `ty=yt+b*z*z`, `tz=zt` で定める
  Ore 族の全4個の重なり曖昧性を `Z[a,b]` 上で検証し、重み4の関係から
  `k*z*z` への射影が `(-a,-b)` であることを確認する。
- 対角 Zhang twist の指標行列、その階数、整数核、3個の不変量、明示的な正規化。

## 射程

証明書は標準数値型と既知の対角量子族の検算である。
一般の関係空間の AS 正則性・Koszul 性や全分類を認証するものではない。
7頂点表示の次元 98、基底変更群の次元 42 は表示の数値であり、
それらの差をモジュライの次元と解釈しない。
3個の twist 不変量は指定した対角 twist 作用を分類するが、
全ての添字保持同型による同一視を分類したものではない。
