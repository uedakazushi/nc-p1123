# 現行の厳密計算

2026-11-19 / v5。証明書は現行版だけを保持する。

Python 3 の標準ライブラリだけを使う。

## n=4 の純基礎Euler条件の方法上の限界

```bash
python3 computations/verify_n4_pure_euler.py
```

研究ノート `note:n4-pure-euler-obstruction` に記載した、s=5、N=7、L=10 の固定形式データを検証する。
階数釣合い・一次モーメント、P=(I-uS)K(I-uS)、3×3 monodromy とその特性多項式を厳密整数で照合する。
`det P=(1-u^10)^3(1+u^20)` と余因子次数の評価により、最初の120係数から全係数を決定できる。
各剰余類の二次多項式表示の正値性を検査し、16,000個の剰余類の不等式を通じて
全 j,k に対する Hopf 次元不等式と左右の単調性を証明する。

この結果は **代数・整域・AS親代数の存在証明ではない**。
純基礎の数値条件と成長条件だけでは非標準型を排除できないことを示す、計算補助の方法上の障害である。
全次数への帰着の証明は研究ノートにあり、コードは固定入力も含む。
大量の係数表や探索履歴は不要である。

## n=4 の一つの親混合Euler延長の排除

```bash
python3 computations/verify_n4_parent_mixed.py
```

研究ノート `note:n4-parent-mixed-obstruction` の固定混合データについて、中央Betti非負性、
三次テンソル交叉の上界、核ベクトルと一次摂動方程式を厳密整数で確認する。
親のAS双対性と純基礎の極位数から必要な行列式の恒等的消滅に対し、
二次係数が `-942` となることを確認する。
このコードが直接確認するのは**表示した一つの混合延長の排除**である。純モデルの親AS整域への全延長は、主論文 `n4:thm:top-word-divisible-three` の解析的証明により不可能である。同定理はこの計算を前提にしない。

## 全対象の混合関係数を強制する有限整数検査

```bash
python3 computations/verify_mixed_ranks.py
```

主論文 `idx:thm:mixed-relation-ranks` の証明に用いる計算を再実行し、
`mixed_ranks_certificate.json` と照合する。意図的に証明書を再生成する場合だけ `--write` を付ける。
AS条件と行列Hilbert級数から解析的に導かれる必要条件は、
`delta_i=r_3(i)-2` が -2 から2の整数、総和0、全隣接和が1以下、
および主論文の7×7対称整数行列 C の行列式が0という条件である。
範囲内78,125列から総和条件を満たす8,135列、さらに隣接条件を満たす890列を列挙する。
890個の行列式をBareiss法で計算し、各除算が整数であることを確認する。
行列式が零となるのは定数零列だけで、これが全 `r_3(i)=2` を与える。

証明書は範囲・行列規約・件数・唯一の生存列・再現用digestを含む。
巨大な候補別出力は収録しない。独立な有理数消去でも全890件を照合済みである。
この検査はAS正則性を仮定した後の必要な数値型の排除であり、
一般の関係データのAS正則性やKoszul性を認証するものではない。

## 基準族と数値的障害例の検算

```bash
python3 computations/weighted_baseline.py
```

このコマンドは整数・有理数・Laurent 単項式の指数ベクトルで計算をやり直し、
現行の `baseline_certificate.json` と比較する。証明書を意図的に再生成する場合は
`--write` を付ける。数値標本や浮動小数点は使用しない。

### 検証する内容

- 指定した標準解消の重みシフトと、二変数 Euler 多項式
  `∏(1-s*t^w_i)`。`s` は語長、`t` は重みである。
- 重み 0〜24 の Hilbert 係数を、幾何級数の積・指数ベクトルの列挙・二重和で独立に照合する。
- 二次関係の各重みの周囲空間、標準関係数、および表示パラメータ空間の次元。
- 対角量子族 `x_j*x_i=q_ij*x_i*x_j` の全4個の重なり曖昧性。
- `x,y,z` が可換、`tx=xt+a*z*z`, `ty=yt+b*z*z`, `tz=zt` で定める
  Ore 族の全4個の重なり曖昧性を `Z[a,b]` 上で検証し、重み4の関係から
  `k*z*z` への射影が `(-a,-b)` であることを確認する。
- 対角 Zhang twist の指標行列、その階数、整数核、3個の不変量、明示的な正規化。
- 研究ノートの数値列 `a=(0,0,0,1,1,2,1)` について、七つの開始行の漸化式と
  monodromy `[[0,0],[8,0]]` を整数演算で再現する。非負のEulerデータであっても、
  主論文 `idx:thm:outer-relation-ranks` のテンソル鎖の議論で実現を排除される例である。

### 基準族の証明書の射程

証明書は標準数値型と既知の対角量子族の検算である。
一般の関係空間の AS 正則性・Koszul 性や全分類を認証するものではない。
7頂点表示の次元 98、基底変更群の次元 42 は表示の数値であり、
それらの差をモジュライの次元と解釈しない。
3個の twist 不変量は指定した対角 twist 作用を分類するが、
この計算だけでは全ての添字保持同型を分類しない。
全同型の必要十分条件は主論文 `diag:thm:indexed-isomorphism` の論理的証明にあり、
正規化後には一つの対合による同一視が残る。
